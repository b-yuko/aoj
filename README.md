# AOJ (Aizu Online Judge) 修行の記録

プログラミングの基礎体力をつけるため、[Aizu Online Judge](https://onlinejudge.u-aizu.ac.jp/home) の問題に挑戦するリポジトリです。

## 🛠 開発環境
- **言語**: Kotlin
- **実行環境**: IntelliJ IDEA (Standard Build System)
- **JDK**: Amazon Corretto 21

## 📂 ディレクトリ構成
コースごとにパッケージを分けて管理しています。

- `src/lesson/itp1/` : Lesson ITP1 プログラミング入門

## 🚀 実行方法
各 `.kt` ファイルを開き、`fun main()` 横の再生ボタン（▶️）から実行します。  
※ AOJ提出時は、`package` 行を除いたコードを貼り付けます。
