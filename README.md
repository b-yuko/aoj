# AOJ (Aizu Online Judge) 修行の記録

プログラミングの基礎体力をつけるため、[Aizu Online Judge](https://onlinejudge.u-aizu.ac.jp/home) の問題に挑戦するリポジトリです。

## 🛠 開発環境
- **言語**: Kotlin
- **実行環境**: IntelliJ IDEA (Standard Build System)
- **JDK**: Amazon Corretto 21

## 📂 ディレクトリ構成
コースごとにパッケージを分けて管理しています。

- `src/lesson/itp1/` : Lesson ITP1 プログラミング入門

## 📝 初回セットアップ
プロジェクトをクローンした直後は、以下の初期設定が必要です（1 回のみ）。

1. メニューバーから `ファイル > プロジェクト構築 > モジュール` を選択し、`src` フォルダーにフォーカスを当てて「マーク:」から「ソース」をクリックします。`src` フォルダーが青くなっていることを確認してください。
2. メニューバーから `ツール > Kotlin > プロジェクトで Kotlin を構成` をクリックし、Kotlin プロジェクトとして認識させます。

この 2 つの手順を行うことで、コードの実行が可能になります。

## 🚀 実行方法
各 `.kt` ファイルを開き、`fun main()` 横の再生ボタン（▶️）から実行します。  
※ AOJ 提出時は、`package` 行を除いたコードを貼り付けます。
